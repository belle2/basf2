Changes in the mva package since release-11-00
----------------------------------------------

* The importance plot produced by ``basf2_mva_evaluate.py`` now preserves the relative magnitudes between variables, by normalising each method's importances so that the column sums to 100. The previous 0 to 100 rescaling discarded this information by mapping the least and most important variables to fixed endpoints. The old behaviour is still available via ``--importance-scale hundredzero``.
* ``FANN`` has been removed from the externals, and the corresponding interface in the ``mva`` package has been removed as well. Neural networks can no longer be trained using ``FANN`` or evaluated using the ``FANN`` library. Users can still train neural networks with ``TMVA`` or export their models trained with other libraries to ``ONNX`` for inference.
* ``MVA::Weightfile`` can now record the version of the contract between a weightfile and the code. This is meant for models whose payload name carries no training version, for example when they are served from a performance globaltag, where the name alone can no longer guarantee that the model fits the code. See :ref:`mva_contract_version`.
