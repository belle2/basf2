Changes in the skim package in light-2607-kasei
--------------------------------------------

FEI skims
+++++++++

* ``FEIPrefix`` is now mandatory. The class-level default has been removed.
  Provide it via the ``feiPrefix`` constructor argument, the ``FEIPrefix``
  instance attribute, or the ``feiPrefix`` parameter of `CombinedSkim`.
  A ``B2FATAL`` is raised if the FEI is run without setting the prefix.

Dark skims
++++++++++

* Added new skim for the Physics channel e^{+}e^{-} \\to \\mu^{+}\\mu^{-}Z^{\\prime}
  `Z^{\\prime} \\to x^{+}x^{-} \\ (x = e, \\mu, \\tau, \\pi, K)
  Registered as ("18520600", "dark", "ZpVisible")
  
* Fixed a bug for the LFVZpVisible skim.
  New LFVZpVisible for PromptRel09 skimming campaign registered as
  ("18520401", "dark", "LFVZpVisible").
  The pre-PromptRel09 skim was made invalid: ("18520400", "dark", "LFVZpVisible_invalid")
