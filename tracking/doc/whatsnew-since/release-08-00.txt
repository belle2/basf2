Changes in the tracking package since release-08-00 (new features of release-09)
--------------------------------------------------------------------------------

Track Refining
++++++++++++++

* The Kink finding was added to the tracking algorithms, which runs in the default chain. It identifies charged particles that decay in flight and are then either reconstructed as one single or two tracks. New Kink objects have been added to store additional TrackFitResults. Information on Kinks can be retrieved via analysis variables. 

Background Rejection
++++++++++++++++++++

* an MVA-based hit filter for the CDC is used in place of the previous cut-based version. A combined (cut-based for the inner SuperLayers + MVA-based for the outer SuperLayers) versionis also available to deal with lower HV in the innermost SuperLayers. (NOTE: the combined filter is _not_ available in release-10)

* the SVD Grouping algorithm is switched on by default, in its so-called "relaxed" configuration (i.e. accpeting the first 4 groups).
